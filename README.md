# روضة الصبيان (Rawdat Al-Sibyan) — Islamic Kids PWA

بداية بسيطة لتطبيق إسلامي تفاعلي للأطفال (1-5 سنين)، أول feature: أذكار الصباح والمساء.

## التشغيل محليًا
```bash
npm install
npm run dev
```

## البناء للنشر
```bash
npm run build
npm run preview
```
بعد الـ build هتلاقي فولدر `dist/` جاهز للنشر على Vercel أو أي static host — نفس طريقة نشر مشروعك التاني.

## هيكل المشروع
- `src/data/adhkar.js` — محتوى الأذكار (سهل تضيف/تعدل منه)
- `src/components/HomeScreen.jsx` — الشاشة الرئيسية (الشمس/القمر بيتغير حسب وقت اليوم)
- `src/components/AdhkarScreen.jsx` — شاشة عرض الأذكار خطوة بخطوة مع نجوم مكافأة
- `public/icons/` — أيقونات placeholder مؤقتة (لونين بسيطين)، يفضّل تستبدلها بأيقونة مصممة فعليًا قبل النشر

## الصوت
زرار 🔊 في شاشات الأذكار والقصص بيشتغل بترتيب 3 مستويات، أوتوماتيك من غير ما تعدل الكود:

1. **تسجيل حقيقي** — لو حطيت mp3 في `public/audio/` وربطته في `audio: '/audio/...'` جوه `src/data/*.js`
2. **TTS سحابي (ElevenLabs)** — أعلى جودة بكتير من صوت المتصفح، لازم تظبطه مرة واحدة:
   - اعمل حساب على [elevenlabs.io](https://elevenlabs.io) وهات API key
   - اختار صوت عربي من مكتبة الأصوات وهات الـ voice ID بتاعه
   - في Vercel: Project Settings → Environment Variables، ضيف:
     - `ELEVENLABS_API_KEY`
     - `ELEVENLABS_VOICE_ID`
   - اعمل Redeploy
   - محليًا: `npm install -g vercel` ثم `vercel dev` بدل `npm run dev` عشان الـ `/api/tts` يشتغل (الملف ده Vercel serverless function، مش هيشتغل مع `npm run dev` العادي)
3. **TTS المتصفح** — fallback تلقائي لو التاني اتعطل أو لسه مش متظبط

التكلفة: ElevenLabs بيدي باقة مجانية محدودة شهريًا، وبعدها بالاشتراك — راجع أسعارهم قبل ما تستخدمه على نطاق واسع.

## ملاحظة فقهية
محتوى الوضوء والصلاة في التطبيق ده مبني على المذهب الحنفي. لسه محتاج مراجعة من شيخ أو مدرّس متخصص قبل النشر للتأكد إن كل التفاصيل مطابقة.

## اللي محتاج شغل بعد كده
- استبدال الأيقونات بتصميم حقيقي
- إضافة feature تاني (قصص الأنبياء أو تعليم الوضوء) بنفس نمط AdhkarScreen
- صوت/تلاوة للأذكار (ممكن نضيف ملفات صوتية وزرار تشغيل)
- شاشة أهل (parent gate) قبل أي إعدادات

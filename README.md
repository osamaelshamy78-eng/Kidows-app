# نور الصغار (Little Noor) — Islamic Kids PWA

بداية بسيطة لتطبيق إسلامي تفاعلي للأطفال (1-5 سنين)، أول feature: أذكار الصباح والمساء.

## التشغيل محليًا
```bash
npm install
npm run dev
```

## البناء للنشر
```bash
npm run build
npm run preview
```
بعد الـ build هتلاقي فولدر `dist/` جاهز للنشر على Vercel أو أي static host — نفس طريقة نشر مشروعك التاني.

## هيكل المشروع
- `src/data/adhkar.js` — محتوى الأذكار (سهل تضيف/تعدل منه)
- `src/components/HomeScreen.jsx` — الشاشة الرئيسية (الشمس/القمر بيتغير حسب وقت اليوم)
- `src/components/AdhkarScreen.jsx` — شاشة عرض الأذكار خطوة بخطوة مع نجوم مكافأة
- `public/icons/` — أيقونات placeholder مؤقتة (لونين بسيطين)، يفضّل تستبدلها بأيقونة مصممة فعليًا قبل النشر

## الصوت
زرار 🔊 في كل الشاشات (الأذكار، القصص، الوضوء، الأسئلة، الألعاب) بيشتغل بترتيب 3 مستويات، أوتوماتيك:

1. **تسجيل حقيقي** — لو حطيت mp3 في `public/audio/` وربطته في `audio: '/audio/...'` جوه `src/data/*.js`
2. **صوت عربي سحابي (ElevenLabs)** — للنص العربي بس. نطق عربي طبيعي بدل لكنة صوت الموبايل:
   - اعمل حساب على [elevenlabs.io](https://elevenlabs.io) وهات API key
   - في Vercel: Project Settings → Environment Variables، ضيف `ELEVENLABS_API_KEY`
   - (اختياري) `ELEVENLABS_VOICE_ID` لو عايز صوت غير الصوت الافتراضي (Haytham)
   - اعمل Redeploy
   - محليًا: `vercel dev` بدل `npm run dev` عشان `/api/tts` يشتغل
3. **صوت الجهاز** — fallback تلقائي، وبيختار أحسن صوت عربي/إنجليزي متاح على الجهاز

الإنجليزي بيستخدم صوت الجهاز على طول لأن كل الأجهزة فيها صوت إنجليزي كويس.

**التوفير في التكلفة:** كل جملة بتتطلب مرة واحدة بس — Vercel CDN بيخزّنها، والتطبيق بيحفظها على الجهاز (بتشتغل أوفلاين بعد أول مرة). الحد الأقصى للجملة 600 حرف.

## الألعاب
كل لعبة في ملف لوحدها في `src/components/games/`، والكلمات والصور المشتركة في `src/data/games.js` — تقدر تضيف كلمات جديدة من هناك وكل الألعاب هتستخدمها.

## ركن الأهل
زرار ⚙️ في الصفحة الرئيسية بيفتح ركن الأهل (اللغة، تشغيل/قفل الصوت، تصفير النجوم). قبله فيه سؤال ضرب بسيط عشان الطفل ميدخلش لوحده — ونفس السؤال بيظهر للخروج من وضع الرضّع.

## ملاحظة فقهية
محتوى الوضوء والصلاة في التطبيق ده مبني على المذهب الحنفي. لسه محتاج مراجعة من شيخ أو مدرّس متخصص قبل النشر للتأكد إن كل التفاصيل مطابقة.

## اللي محتاج شغل بعد كده
- استبدال الأيقونات بتصميم حقيقي
- إضافة feature تاني (قصص الأنبياء أو تعليم الوضوء) بنفس نمط AdhkarScreen
- تسجيلات صوتية حقيقية للأذكار (بصوت قارئ) بدل الصوت المُولّد

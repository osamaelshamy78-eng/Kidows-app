# Icon concepts — نور الصغار / Little Noor

Hand-authored SVG (Recraft was not connected in the session that made these).

Brief:
- Subject: app icon for a children's Islamic app named "نور الصغار" (Little Noor = "light of the little ones"); one concept per file
- Style: flat vector, soft rounded shapes, friendly for ages 1–5
- Palette: cream #FBF6EC, teal #2A6F6F / #1D4E4E, gold #E8A33D / #F4C978, brick #B5573A
- Background: full-bleed (PWA maskable icon), key shapes inside the central safe zone
- Output: SVG, 512×512
- Variants: 3 — A crescent & star, B lantern, C teal crescent on a light disc

`montage.png` shows each at home-screen sizes on light and dark backgrounds.
